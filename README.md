# Wayfire-Copr
Copr: https://copr.fedorainfracloud.org/coprs/reasonablekat/wayfire/

An attempt to bring and updated [Wayfire](https://github.com/WayfireWM/wayfire) package and extras to Fedora.

This was mainly a learning experience in packaging for Fedora, there is no guarantee of continued updates, use at your own discretion.

This is a personal project unaffiliated with WayfireWM \
**DO NOT REPORT ISSUES TO WAYFIREWM WHEN USING THESE PACKAGES**
